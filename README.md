# Adil Sukumar

Integrated M.Tech. student in **Artificial Intelligence and Bioinformatics** at VIT Bhopal University. I build computational systems for biological and real-world data, with interests in machine learning, scientific computing, genomics, and multimodal sensor analysis.

My goal is to move beyond applying existing tools and learn how robust computational methods can answer scientific questions. I am especially interested in messy, high-dimensional data where modelling choices, validation, and biological interpretation matter as much as the final prediction.

## Current focus

- Machine learning for scientific and biological data
- Genomics and reproducible bioinformatics workflows
- Time-series, multimodal sensor data, and computer vision
- Reliable evaluation, uncertainty, and honest communication of model limits
- Turning research prototypes into maintainable systems

## Technical toolkit

**Languages:** Python, TypeScript/JavaScript, C++, Bash, SQL

**ML and data:** PyTorch, TensorFlow, scikit-learn, OpenCV, MediaPipe, signal/time-series processing

**Bioinformatics:** SRA Toolkit, FastQC/MultiQC, BWA, SAMtools, GATK, SnpEff/SnpSift

**Engineering:** FastAPI, React, Docker, AWS, Git, Linux, Supabase, ESP32

## How I work

I enjoy owning the path from an unclear problem to a testable system: understanding the data, building the pipeline, connecting components, documenting limitations, and revising the approach when evidence contradicts the first idea. I am currently looking for research environments where I can deepen the mathematical and scientific side of that work.
